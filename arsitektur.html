Arsitektur Lab: 3 Virtual Machine

Satu master + dua worker di bawah manajemen Rancher.

Tabel spesifikasi contoh lab

VM Peran vCPU RAM Disk OS contoh
VM-1 Master / control-plane 2 4 GB 40 GB Ubuntu Server 22.04
VM-2 Worker 2 4 GB 40 GB Ubuntu Server 22.04
VM-3 Worker 2 4 GB 40 GB Ubuntu Server 22.04

Spesifikasi bersifat contoh edukasi; sesuaikan dengan resource hypervisor Anda (VirtualBox, VMware, Proxmox, dsb.).

Komponen di Master

  1. API Server — pintu masuk cluster
  2. etcd — penyimpanan state
  3. Scheduler — menempatkan Pod ke worker
  4. Controller Manager — menjaga kondisi diinginkan

Komponen di Worker

  • kubelet — agen node
  • kube-proxy — aturan jaringan Service
  • Container runtime (containerd/Docker)
  • Pod aplikasi mahasiswa / demo

Checklist jaringan lab

Pastikan ketiga VM saling terhubung dan dapat mencapai server Rancher:

  • IP statis atau DHCP reservation untuk setiap VM
  • Hostname unik: k8s-master, k8s-worker1, k8s-worker2
  • Port yang dibutuhkan Rancher/K8s tidak diblok firewall lokal
  • Sinkronisasi waktu (NTP) agar sertifikat tidak bermasalah

Perintah cek cepat di tiap VM

hostnamectl
ip a
ping -c 2 192.168.56.11
ping -c 2 <IP-RANCHER>
timedatectl status
sudo ufw status || true
