Media Pembelajaran

Demonstrasi elemen <video> dan <audio> (Materi Sesi 11 & 12).

Video HTML5 — contoh pemutar lokal

Tag video menampilkan pemutar bawaan browser. Atribut controls, poster (opsional), dan beberapa sumber format meningkatkan kompatibilitas.

File contoh bersifat demonstrasi elemen media. Ganti dengan rekaman lab Anda sendiri saat presentasi.

Audio HTML5 — intro lab

Tag audio dipakai untuk narasi singkat atau sinyal pembuka modul. Contoh di bawah menggunakan berkas WAV hasil generate untuk demo kontrol pemutar.

Atribut penting

  • controls — tampilkan tombol play/pause
  • preload — strategi muat metadata/berkas
  • Beberapa <source> untuk fallback format

Video referensi eksternal (embed)

Selain file lokal, konten edukasi sering disematkan dari platform video. Contoh embed di bawah memakai materi publik tentang Rancher / Kubernetes (What is Rancher?).

Jika muncul kotak hitam / Error 153 saat dibuka lewat file://, jalankan via Live Server (http://localhost) agar browser mengirim Referer ke YouTube.

Cadangan tautan langsung: buka di YouTube. Untuk vlog sendiri, ganti src iframe menjadi https://www.youtube-nocookie.com/embed/ID_VIDEO_ANDA.
