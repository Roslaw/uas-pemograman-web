Mengapa contoh 3 VM?

Tiga mesin virtual cukup untuk meniru lingkungan produksi kecil: satu node mengurus control-plane, dua node menjalankan workload. Pola ini cocok untuk laboratorium kampus maupun belajar mandiri.

  • Master: API Server, Scheduler, Controller Manager, etcd
  • Worker A & B: kubelet menjalankan Pod aplikasi Anda
  • Rancher: antarmuka untuk provisioning dan monitoring
