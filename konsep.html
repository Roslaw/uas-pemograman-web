Konsep Kubernetes & Rancher

Dasar teori singkat sebelum merakit cluster 3 VM.

Apa itu Kubernetes?

Kubernetes (K8s) adalah platform orkestrasi kontainer yang mengatur penjadwalan, penskalaan, dan pemulihan aplikasi. Cluster terdiri dari node control-plane (master) dan node worker.

Istilah penting: Pod (unit deploy), Deployment (menjaga replika), Service (akses jaringan stabil), dan Namespace (isolasi logis).

Apa itu Rancher?

Rancher menyediakan antarmuka manajemen untuk membuat dan mengoperasikan cluster Kubernetes. Alih-alih merangkai semua komponen control-plane secara manual, Anda dapat:

  • Membuat cluster dari UI Rancher
  • Menjalankan perintah registrasi (curl ... | sh) pada VM master/worker
  • Memantau kesehatan node dan workload

Contoh perintah yang sering muncul di lab (nilai token diganti dari UI):

# Di host Rancher — jalankan server
sudo docker run -d --restart=unless-stopped \
  -p 80:80 -p 443:443 --privileged \
  --name rancher rancher/rancher:latest

# Di node (setelah Create Cluster di UI) — contoh join worker
curl -fL https://<IP-RANCHER>/system-agent-install.sh | sudo sh -s - \
  --server https://<IP-RANCHER> \
  --token <CLUSTER_TOKEN> \
  --worker

Detail langkah lengkap ada di halaman Panduan.

Perintah kubectl dasar (wajib dikenal)

Setelah cluster Ready, perintah berikut paling sering dipakai:

kubectl get nodes -o wide
kubectl get pods -A
kubectl describe node k8s-master
kubectl create deployment demo --image=nginx
kubectl get deploy,svc
kubectl logs deploy/demo
kubectl delete deployment demo

Glosarium singkat

Control-plane
Otak cluster: API server, scheduler, controller, etcd.
Worker
Node yang menjalankan Pod aplikasi lewat kubelet.
etcd
Basis data key-value untuk state cluster.
CNI
Plugin jaringan antar Pod (misalnya Canal/Calico).

Apakah master boleh menjalankan Pod? Bisa (taint dihapus), tetapi di lab ini master dikhususkan untuk control-plane agar konsepnya jelas.
Versi yang dipakai? Gunakan rilis Rancher/K8s stabil yang didukung dokumentasi resmi saat praktikum.
